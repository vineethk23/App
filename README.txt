Indie Gen-2 Fault Code Lookup - installable offline app (PWA)

1. Upload ALL files in this folder to any HTTPS web host
   (Netlify Drop, GitHub Pages, Firebase Hosting, Cloudflare Pages - all free).
2. Open the link on the phone in Chrome (Android) or Safari (iPhone).
3. Android: menu > Install app / Add to Home screen.
   iPhone: Share > Add to Home Screen.
4. Open it once with internet. After that it works fully offline.

To update later: upload new files and change 'fault-codes-v1' in sw.js to v2.
